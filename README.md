# Daily Expense Tracker

A simple, secure Daily Expense Tracker built with .NET 10, ASP.NET Core, Clean Architecture, Entity Framework Core, and MySQL.

## Project Structure

```text
DailyExpenseTracker/
│
├── src/
│   ├── DailyExpenseTracker.Domain/
│   ├── DailyExpenseTracker.Application/
│   ├── DailyExpenseTracker.Infrastructure/
│   └── DailyExpenseTracker.Web/
│
├── tests/
│   ├── DailyExpenseTracker.Application.Tests/
│   └── DailyExpenseTracker.IntegrationTests/
│
├── docs/
│
├── .gitignore
├── README.md
└── PROJECT_SPEC.md
```

## Getting Started

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/)
- MySQL Server

### Build
```bash
dotnet build
```
